# Cuerpo Coffee

English-language coffee publication. See `CLAUDE.md` for project rules and
`docs/TECHNICAL-PLAN.md` for the full spec.

## Commands

Run these from the project root, in a terminal:

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies (only needed once, or after a dependency changes) |
| `npm run dev` | Start the local dev server at `localhost:4321` |
| `npm run build` | Build the production site to `./dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run check` | Check for type and template errors |
